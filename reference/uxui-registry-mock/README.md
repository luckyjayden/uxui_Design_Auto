# UXUI 블록 레지스트리 프로토타입의 파일 묶음 (목업)

사용자가 만든 프로토타입 "UXUI 블록 레지스트리_V0.2.html"의 "공유 기반" 화면이 만들어 보여 주는 저장소 파일 35개를 그대로 꺼낸 것입니다. 2026-11-25에 추출했습니다.

- **전부 목업 데이터입니다.** 블록 25개, 사람 이름, 프로젝트, 피그마 파일 키, 추출 결과, 커밋 해시가 모두 시연용입니다.
- 코드 연결이 있는 블록은 12개이고 패키지(`@uxui/core`, `@uxui/blocks`)는 실제로 없습니다.
- `requests/` 폴더는 프로토타입이 파일 내용을 만들지 않아 들어 있지 않습니다.
- 이 폴더는 참고용이며 고치지 않습니다. 실제 블록 라이브러리를 만들 때 구조의 출발점으로 씁니다.

실제로 쓰기 전에 정해야 할 것은 [정책서](../../docs/02-policy.md)의 미정 사항에 있습니다. 요청 ID(REQ-0000)가 요구사항 ID(REQ-000)와 접두어가 겹치는 문제가 그중 하나입니다.
