# 요구사항 정의서: AI UX 설계 자동화 시스템

## 1. 문서 개요

이 문서는 AI UX 설계 자동화 시스템이 갖춰야 할 요구사항을 ID와 함께 정리한 것입니다. [프로젝트 정의서](00-project-definition.md)의 목적과 범위를 요구사항으로 풀고, [정책서](02-policy.md)와 [기능 정의서](03-functional-spec.md)가 이 문서의 ID를 참조합니다.

요구사항은 새로 지어내지 않고 이미 있는 문서에서 뽑았습니다. 프로젝트 정의서, 기능 정의서, [결정 기록](decisions.md)이 출처이며 항목마다 출처를 적었습니다. 기능 정의서가 먼저 쓰였기 때문에, 이 문서는 기능(FN)에서 거꾸로 요구사항을 정리한 초안입니다.

| 항목 | 내용 |
| --- | --- |
| 상태 | 검토 필요. Claude가 쓴 초안이며 사람의 승인 전입니다. |
| ID 규칙 | REQ-000. 한 번 붙인 ID는 바꾸거나 재사용하지 않습니다. |
| 유형 | 기능, 비기능, 제약 |
| 단계 | 그 요구사항을 처음 검증하는 [로드맵](roadmap.md) 단계입니다. 프로토타입, 개발, 전 단계 중 하나이며 Claude의 제안입니다. |
| 처리용 데이터 | [data/requirements.json](data/requirements.json) |

사용자 유형은 프로젝트 정의서 3절을 따릅니다. 주 사용자는 기획자이고, UI 블록 담당자와 개발·QA 담당자가 함께 씁니다.
