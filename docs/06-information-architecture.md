# 정보 구조도: AI UX 설계 자동화 시스템

이 문서는 아직 쓰지 않았습니다. 자리와 목차만 잡아 두었습니다.

## 이 문서가 담을 것

이 시스템의 화면 구조입니다. 화면 목록과 화면 ID, 화면 사이의 이동을 적습니다. 웹 구동 방식 확정에 따라 [기능 정의서](03-functional-spec.md) 4절이 화면을 세션·GitHub·뷰어로 나눠 두었습니다. 뷰어 화면 7개(STU-01~02, STU-04~08)가 이 문서의 초안이고 STU-03은 폐기됐습니다.

화면을 화면설계서 작성의 작업 단위(WU)로 묶는 것도 정보 구조도에서 합니다(POL-035). 이 시스템 자체가 파일럿이므로 뷰어 화면의 작업 단위도 이 문서에서 정합니다.

## 예정 목차

1. 문서 개요와 ID 규칙 (STU-00)
2. 화면이 놓이는 곳: claude.ai/code, GitHub, 뷰어
3. 화면 목록과 계층
4. 화면 사이의 이동
5. 화면과 기능(FN)의 대응
6. 미정 사항
