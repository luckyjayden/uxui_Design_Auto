# 정보 구조도: AI UX 설계 자동화 시스템

이 문서는 아직 쓰지 않았습니다. 자리와 목차만 잡아 두었습니다.

## 이 문서가 담을 것

이 시스템의 화면 구조입니다. 화면 목록과 화면 ID, 화면 사이의 이동을 적습니다. 기능 정의서 4절의 대시보드 화면 8개(STU-01~08)가 초안이며, 웹 구동 방식이 확정되면 claude.ai/code, GitHub, 뷰어로 역할을 다시 나눠야 합니다.

## 예정 목차

1. 문서 개요와 ID 규칙 (STU-00)
2. 화면이 놓이는 곳: claude.ai/code, GitHub, 뷰어
3. 화면 목록과 계층
4. 화면 사이의 이동
5. 화면과 기능(FN)의 대응
6. 미정 사항

## 쓰기 전에 필요한 것
