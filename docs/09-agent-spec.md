# 에이전트 명세: AI UX 설계 자동화 시스템

## 이 문서가 담을 것

전문 에이전트 6개와 총괄 에이전트의 명세입니다. 에이전트마다 읽는 것, 만드는 것, 시작 조건, 완료 조건, 하지 말아야 할 것을 적습니다. 웹 구동 검토안에서는 이 문서가 `.claude/agents/`의 명세 파일과 `CLAUDE.md`의 총괄 규칙으로 옮겨집니다.

## 예정 목차

1. 문서 개요
2. 총괄 규칙: 실행 순서, 시작·완료 조건, 상황별 처리
3. Requirements Agent
4. Policy Agent
5. Flow Agent
6. IA Agent
7. Screen Agent
8. QA Agent
9. 권한 규칙과 훅: 자기 문서 밖 쓰기 차단, 사람이 고친 항목 보존
10. 미정 사항
