# 정책서: AI UX 설계 자동화 시스템

## 1. 문서 개요

이 문서는 AI UX 설계 자동화 시스템이 따르는 규칙을 ID와 함께 정리한 것입니다. 정책마다 [요구사항 정의서](01-requirements.md)의 요구사항을 하나 이상 참조합니다.

정책은 새로 지어내지 않고 이미 있는 문서에서 뽑았습니다. [프로젝트 정의서](00-project-definition.md), [기능 정의서](03-functional-spec.md), [결정 기록](decisions.md), 블록 레지스트리 프로토타입이 출처입니다.

| 항목 | 내용 |
| --- | --- |
| 상태 | 검토 필요. Claude가 쓴 초안이며 사람의 승인 전입니다. |
| ID 규칙 | POL-000. 한 번 붙인 ID는 바꾸거나 재사용하지 않습니다. |
| 처리용 데이터 | [data/policies.json](data/policies.json) |

정책마다 확정 여부를 적었습니다.

| 확정 여부 | 뜻 | 개수 |
