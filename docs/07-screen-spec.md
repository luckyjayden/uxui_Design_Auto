# 화면설계서: AI UX 설계 자동화 시스템

이 문서는 아직 쓰지 않았습니다. 자리와 목차만 잡아 두었습니다.

## 이 문서가 담을 것

이 시스템의 화면(뷰어) 설계입니다. 화면마다 구성, 인터랙션, 디스크립션, 예외 상황을 적습니다. 이 시스템이 만들어 내는 화면설계서와 같은 형식(화면설계서 JSON)으로 쓰면 뷰어의 첫 시험 데이터로도 쓸 수 있습니다.

## 예정 목차

1. 문서 개요
2. 화면별 설계: 구성, 인터랙션, 디스크립션, 예외 상황
3. 화면에서 쓰는 UI 블록
4. 미정 사항
