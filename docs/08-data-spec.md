# 데이터 규격: AI UX 설계 자동화 시스템

이 문서는 아직 쓰지 않았습니다. 자리와 목차만 잡아 두었습니다.

## 이 문서가 담을 것

프로젝트 데이터 저장소의 파일 구조와 JSON 스키마입니다. 기능 정의서 5절의 데이터 정의를 스키마 파일 수준으로 구체화합니다.

## 예정 목차

1. 문서 개요
2. 폴더 구조
3. 공통 필드와 ID 규칙
4. 문서별 JSON 스키마: 요구사항, 정책, 유저 플로우, 워크 플로우, 정보 구조도, 화면설계서, 검증 결과
5. 상태·실행·변경 기록(_meta)의 스키마
6. UI 블록 참조 규칙
7. 검증 스크립트가 검사하는 것
8. 미정 사항

## 쓰기 전에 필요한 것

- 요청 ID와 요구사항 ID의 접두어 충돌 해소.
- 화면설계서 JSON의 props 키 결정.
- [정책서](02-policy.md)의 데이터와 ID 정책(POL-013~017, POL-033) 확정.
